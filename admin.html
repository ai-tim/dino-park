Подарки сразу уходят на серверы сообщений, но те могут их забыть. Чтобы подарки хранились надёжно, страница записывает их в файл gifts/feed.json сайта на GitHub. Для этого нужен ключ доступа GitHub (токен) — он хранится только в этом браузере.
  1. Открой github.com → Settings → Fine-grained tokens → Generate new token (войди в аккаунт, где лежит сайт).
  2. Token name: Динопарк подарки. Expiration: 1 год (или дольше).
  3. Repository access: Only select repositories → выбери dino-park.
  4. Permissions → Repository permissions → Contents: Read and write. Больше ничего не включай.
  5. Нажми Generate token, скопируй его (начинается с github_pat_) и вставь сюда:
