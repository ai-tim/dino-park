# Предыдущая версия Динопарка

Здесь сохранена прежняя версия сайта (Three.js-демо парка, сканер, панель управления).
Все относительные ссылки внутри `legacy/` работают как раньше: откройте `legacy/index.html`.
Исходные записи голосов (`demos/audio/*.mp3`) используются для сборки голосов новой версии
(`tools/make-voices.sh` → `assets/audio/voices/`).
